# 🌱 두더지 농장 (Mole Farm)

밭을 갈아 씨를 뿌리고, 물과 비료를 주고, 몰려오는 두더지를 망치로 때려잡고,
수확물을 시장 시세를 보며 팔아 다시 밭을 넓히는 **농장 경영 게임**입니다.

**데스크톱(마우스 + 키보드)과 모바일(터치)을 하나의 코드로 모두 지원**하며,
빌드 도구·외부 라이브러리·서버가 전혀 필요 없습니다. (순수 HTML + CSS + JavaScript)

## 바로 실행하기

### 1) 파일 하나로 실행 (가장 쉬움) ⭐
**`game/mole-farm.html` 한 파일만** 내려받아 더블클릭하면 끝입니다.
CSS·JS·아이콘이 전부 안에 들어 있어 다른 파일이 필요 없고, 인터넷도 필요 없습니다.
메신저로 보내거나 USB에 담아 옮겨도 그대로 실행됩니다.

> ⚠️ ZIP을 받았다면 **반드시 압축을 먼저 풀고** 여세요.
> 압축 파일 안에서 `index.html`을 바로 더블클릭하면 윈도우가 그 파일 하나만
> 임시폴더(`AppData\Local\Temp\...`)에 꺼내 열기 때문에, 옆에 있어야 할
> `css/`·`js/` 폴더를 못 찾아 **글자만 나오고 게임이 안 뜹니다.**
> (이 문제가 아예 없는 게 위의 `mole-farm.html` 단일 파일입니다.)

### 2) 원본 폴더로 실행
압축을 푼 뒤 `game/index.html`을 열면 됩니다. (`index.html`, `css/`, `js/`가
같은 폴더에 함께 있어야 합니다.)

### 3) 로컬 서버로 실행 (같은 와이파이의 휴대폰에서도 접속 가능)
```bash
cd game
python3 -m http.server 8000
# 데스크톱:  http://localhost:8000
# 휴대폰:    http://<PC의 내부 IP>:8000   (예: http://192.168.0.12:8000)
```

### 4) 휴대폰 홈 화면에 앱처럼 설치 (PWA)
HTTPS로 서비스되는 주소에서 열면(예: GitHub Pages) `manifest.webmanifest` + `sw.js` 덕분에
**홈 화면에 추가**로 설치되고, 이후에는 오프라인에서도 실행됩니다.
GitHub Pages로 올리려면 저장소 **Settings → Pages → Source: main 브랜치 / 루트**로 지정한 뒤
`https://<사용자>.github.io/<저장소>/game/` 로 접속하면 됩니다.

## 게임 방법

| 단계 | 조작 |
|---|---|
| ⛏️ 경작 | 잠기지 않은 풀밭을 탭/클릭해 밭으로 만듭니다 (드래그로 여러 칸) |
| 🌱 씨앗 | 🌱 버튼을 한 번 더 누르면 작물 선택창. 밭을 탭하면 씨앗값을 내고 심습니다 |
| 💧 물 | 수분이 0이 되면 성장이 거의 멈추고, 오래 방치하면 작물이 말라 죽습니다 |
| 🧪 비료 | 성장 속도 1.7배 + 수확량 증가 + ✨황금 등급(판매가 2.4배) 확률 |
| 🔨 망치 | 두더지가 튀어나오면 링이 다 돌기 전에 두드려 잡습니다 |
| 🧺 수확 | 성장 게이지가 꽉 찬 작물을 거둬 창고에 넣습니다 |
| 📈 시장 | 작물 시세는 매일 아침 새로 형성됩니다. 비쌀 때 파세요 |
| 🏪 상점 | 밭 확장, 스프링클러, 허수아비, 밭고양이, 시장 분석 리포트 등 |

- 두더지를 **연속으로** 잡으면 콤보 배수만큼 보상이 커집니다. 망치가 아닌 도구로 치면 쫓아내기만 하고 보상은 없습니다.
- 제한 시간 안에 못 잡으면 그 칸의 작물을 통째로 먹어치웁니다.
- 날씨(맑음/흐림/비/가뭄)에 따라 성장·수분 소모·두더지 출현 빈도가 달라지고, 밤에는 성장이 느려집니다.
- 레벨이 오르면 새 작물이 해금됩니다 (당근 → … → 황금사과).

### 키보드 (데스크톱)
`1`~`6` 도구 전환 · `W` 전체 물주기 · `H` 전체 수확 · `S` 상점 · `M` 시장 · `B` 창고 · `Esc` 닫기

## 저장

진행 상황은 브라우저 `localStorage`에 자동 저장됩니다(6초마다 + 앱을 벗어날 때).
게임을 꺼둔 동안에도 **최대 2시간까지** 작물이 자라고 수분이 마릅니다.
초기화는 ⚙️ 메뉴 → 새로 시작.

## 코드 구조

```
game/
├── index.html              화면 뼈대
├── mole-farm.html          ⭐ 전부 합친 단일 실행 파일 (build_standalone.py로 생성)
├── build_standalone.py     단일 파일 생성 스크립트
├── css/style.css           반응형 UI (모바일 세로/가로, 데스크톱)
├── manifest.webmanifest    PWA 설치 정보
├── sw.js                   오프라인 캐시
├── icon.svg                아이콘
└── js/
    ├── config.js   작물/도구/업그레이드/날씨 등 모든 수치
    ├── util.js     공용 헬퍼
    ├── audio.js    WebAudio로 즉석 합성하는 효과음 (음원 파일 없음)
    ├── market.js   평균회귀 랜덤워크 기반 시세 엔진
    ├── game.js     상태·규칙 (성장, 수분, 두더지, 레벨, 저장/오프라인 보정)
    ├── render.js   캔버스 렌더링 (모든 그래픽을 코드로 그림, 세로 화면에선 밭을 자동 회전)
    ├── ui.js       HUD·툴바·상점/시장/창고/메뉴 패널
    ├── input.js    포인터(마우스+터치) & 키보드 입력
    └── main.js     부팅 & 게임 루프
```

`js/`나 `css/`를 고친 뒤에는 `python3 build_standalone.py`를 다시 실행해
`mole-farm.html`을 갱신하세요.

밸런스를 바꾸고 싶으면 `js/config.js`의 숫자만 고치면 됩니다.
새 작물은 `FG.CROPS` 배열에 한 줄 추가하면 시장·상점·창고에 자동으로 반영됩니다.
