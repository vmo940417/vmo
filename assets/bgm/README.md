# 배경음악 음원 폴더

이 폴더에 있는 오디오 파일(mp3/m4a/wav/ogg)이 자동으로 배경음악으로 사용됩니다.
`scripts/bgm.py`가 영상 제목을 시드로 삼아 파일 중 하나를 순환 선택하고, 영상 길이에
맞게 자르거나 반복하고, 라우드니스를 일정하게 정규화해서 내레이션과 믹싱합니다.

## 음원 추가하는 법

1. [YouTube Studio](https://studio.youtube.com) 접속 → 왼쪽 메뉴 **오디오 보관함**
2. 장르 필터에서 "Cinematic", "Ambient", "Corporate/Uplifting" 등에서 밝고 에너지 있는
   느낌의 곡을 2~4개 정도 고르기 (저작권 걱정 없는 무료 음원, 대부분 저작자 표시도
   필요 없음 — 다운로드 화면에 표시된 라이선스 문구만 확인하면 됩니다)
3. mp3로 다운로드해서 이 폴더(`assets/bgm/`)에 넣고 커밋

파일이 하나도 없으면 배경음악 없이(내레이션+자막만) 영상이 만들어집니다 — 파이프라인이
깨지지 않도록 자동으로 건너뜁니다.

## 끄기/볼륨 조정

README.md 1-5절 참고 (`BGM_ENABLED=0`으로 끄기, `BGM_VOLUME`으로 미세 조정,
`BGM_TARGET_LUFS`로 절대 라우드니스 기준 조정).
