# 자작곡 폴더

이 폴더에 넣어둔 오디오 파일(mp3/m4a/wav/ogg)이 매일 만들어지는 영상에서 **나레이션(명언
낭독) 구간이 끝난 직후** 이어붙는 "자작곡 구간"으로 사용됩니다. 배경 이미지는 화면 전환
없이 나레이션 구간과 자작곡 구간에 걸쳐 계속 같은 줌인 애니메이션이 이어지고, 자작곡
구간에는 자막이 없습니다.

예: 기존 20초(나레이션) 영상 + 곡 = 총 1분 안팎짜리 영상.

## 지금 들어있는 곡

- `차분_calm.mp3` — 차분하게 하루를 여는 느낌 (46.9초)
- `활기_energetic.mp3` — 활기차게 하루를 여는 느낌 (68.5초)

`scripts/song.py`가 **매일 KST 날짜 기준으로 이 둘을 정확히 번갈아** 선택합니다 (하루는
차분한 곡, 다음 날은 활기찬 곡). 같은 날 여러 번 실행돼도(수동 재실행 등) 항상 같은 곡이
나오도록 날짜(순번)로 순환하지, 무작위로 고르지 않습니다.

## 곡 추가/교체하는 법

- 곡을 더 추가하면(3개, 4개…) 그만큼 더 긴 주기로 순환됩니다 (파일명 알파벳 순으로 순번이
  매겨집니다).
- 곡을 바꾸고 싶으면 이 폴더의 파일을 교체(또는 삭제 후 새 파일 추가)하고 커밋하면, 다음
  실행부터 바로 반영됩니다.
- 실행 로그의 `[song] 오늘 선택된 곡: ...` 줄에서 그날 어떤 곡이 쓰였는지 확인할 수
  있습니다.

## 끄기/볼륨 조정

- `SONG_ENABLED=0` — 자작곡 구간 없이 기존처럼 나레이션 길이만큼만 만듭니다.
- `SONG_TARGET_LUFS` (기본 `-16`) — 절대 라우드니스 목표치. `assets/bgm/`의 배경음악보다
  크게(더 크게 들리도록 -16, bgm 기본은 -25) 잡혀 있습니다 — 이 구간에서는 곡이 배경이
  아니라 "메인으로 듣는 음악"이기 때문입니다.

폴더가 비어 있으면 자작곡 구간 없이(기존과 동일하게) 영상이 만들어집니다 — 파이프라인이
깨지지 않도록 자동으로 건너뜁니다.
