# 기존 `KTB10 ... v2.xlsm` 분석

사용자가 실제로 쓰던 워크북을 분해해 모형을 파이썬으로 재현하고 대조한 결과.
간소판(`국채선물_차익거래_간소.xlsx`)은 이 분석을 근거로 만들었다.

## 원본 구조

| 항목 | 내용 |
|---|---|
| 시트 | `10년선물` 단 하나 (389행 × 29열) |
| 벤더 | 연합인포맥스 (`_xll.IMDP`) |
| 바스켓 | **2종목** — 국고 25-5(만기 2035-06-10), 국고 25-11(만기 2035-12-10) |
| 단가계산 | VBA UDF `채권단가6월(y, cr, 발행일, 만기일, 매매일, 전이자일, 다음이자일)` |
| 기타 매크로 | `선도이자율3년/5년` — GoalSeek 으로 선도이자율 역산 |

### 인포맥스 심볼

```
선물 현재가 : IMDP("FUT","A6769000","선물호가_현재가")
선물 이론가 : IMDP("FUT","A6766000","이론가")          ← 코드가 위와 다름
채권 수익률 : IMDP("BND","KR103503GG60","장내국채-매도수익률1")
```

실시간으로 받는 것은 **국고 25-11 한 종목뿐**이고, 국고 25-5 는 `G4 = K8 − 2.6bp`
로 고정 스프레드 파생한다.

## 검증된 것

`채권단가6월` UDF 는 한국 채권시장 관행식과 **정확히 동일**하다.
이표일을 올바르게 넣으면 독립 구현과 차이가 `0.00e+00` 이다.

```
UDF  : (BondP1 + BondP2) / (1 + y/2 × 이표잔존일수/이표구간일수)
관행식: [Σ CF_k /(1+y/2)^(k-1)] / (1 + y/2 × d/T)
```

계산 코어 자체는 신뢰할 수 있다. 아래 문제들은 전부 그 **바깥**에 있다.

## 발견한 문제

### 1. 캐리 이중계상 (가장 중요)

`N10`(이론가)을 바스켓 **현물**금리로 산출한다. 선물가격에는 원래 캐리가 반영돼
있으므로, 이 이론가와 시장가의 차이 `O10` 이 **곧 캐리**다. 그런데 `O2`/`O3` 에서
캐리 현금항을 한 번 더 더한다.

파일 캐시값(현물 4.322%, 조달 2.6%, 잔존 49일)으로 검증:

| | 값 |
|---|---|
| 현물금리 기준 이론가 `N10` | 105.4596 (파일 캐시 105.45 ✓) |
| 선도금리(4.3505%) 기준 이론가 | 105.2214 |
| 차이 | **0.2382 포인트 = 계약당 238만원** |
| 별도로 더한 캐리 현금항 | **계약당 250만원** |

두 값이 같은 대상이다. 결과적으로 `O10 = +0.22` 가 매일 **"선물 0.22포인트 저평가"**
라는 유령 신호를 만든다. 선도금리로 계산하면 베이시스는 **+0.0086포인트
(계약당 약 1.5만원)** 로 사실상 균형이며, 유동성 좋은 선물이라면 이쪽이 정상이다.

증상: `O2`(매도차익)와 `O3`(매수차익)가 **동시에 음수**(-472만 / -266만)다.
부호를 바로잡으면 이번엔 동시에 양수가 되는데, 양방향 차익은 성립할 수 없다.

### 2. 이표일 하드코딩 → 스테일

`Q7`/`Q8`(차기이표일)이 **2026-06-10** 고정. 현재일이 2026-07-29 이므로
**이표잔존일수 = −49일**(음수)이 되어 단가가 부풀려진다.

| 종목 | 스테일 단가 | 정상 단가 | 오차 |
|---|---|---|---|
| 국고 25-5 | 89.3775 | 88.0437 | **+1.33원** (액면 1억당 +133만원) |
| 국고 25-11 | 93.7967 | 92.1478 | **+1.65원** (액면 1억당 +165만원) |

올바른 차기이표일은 둘 다 2026-12-10. 만기일에서 6개월씩 역산하면 자동으로 나온다.

### 3. `H7`/`H8` 선도가격이 `#VALUE!`

```
H7 = ROUNDDOWN(IF($B$2>Q7,(G7-C7/2*100)*(1+$F$2*$D$2/365), ...
```
`$F$2` 를 금리로 참조하는데 `F2` 의 실제 내용은 **"장내매도기준"이라는 텍스트**다.
선도가격 열 전체가 무효. (파일에 저장된 캐시값으로 확인 — 오류 셀은 이 2개뿐)

### 4. 선물 듀레이션 `O9` 의 인자 오류

```
O9 = DURATION(B2, B2+10y, 8%, N9, 2, 3) + DURATION(C2, B2, 8%, N9, 2, 3)
```
- 표준물 쿠폰은 **5%** 인데 8% 를 씀
- 수익률 인자 `N9` 가 **공란(=0%)**
- 맥컬레이 듀레이션 두 개를 더함

결과 8.0259년 vs 정답(표준물 수정듀레이션) 7.8778년 → **+1.9% 오차**.
계약수 `P7`/`P8` 이 그만큼 적게 잡힌다. 오차가 우연히 작은 편이라 눈에 띄지 않았을 것.

### 5. 기타

- `I7`/`I8`(선도이자율) = 3.97% / 3.10% 하드코딩. GoalSeek 산출물인데 현재 금리
  4.32% 와 동떨어진 **stale 값**이라 검증열 `J7`/`J8` 도 의미가 없다.
- 선물 코드가 `A6769000`(현재가) vs `A6766000`(이론가)로 **다르다**.
  다른 결제월이면 34행 이론가 비교가 어긋난다.
- 국고 25-5 의 −2.6bp 스프레드는 수동 갱신이 필요하다.

### 오류가 아니었던 것

캐리항 `M2/365*D2*G9*200000000` 의 `×2억` 이 처음엔 100배 단위 오류로 보였으나,
확인 결과 **액면 200억 기준으로 일관**된다(171계약 × 헤지비율 1.199 ≈ 205억).
단가 `G9` 를 곱해 액면→시가 환산까지 맞다.

## 간소판에 반영한 것

가져온 것: 단일 시트 지향 구성, 인포맥스 `IMDP` 실수식, 2종목 바스켓,
포지션 손익 표.

고친 것: 위 1~4번 전부. 이론가를 선도금리 기준으로 바꾸고, 이표일을 만기일에서
자동 역산하며, 표준물 BPV 를 정식 폐쇄형으로 계산하고, 텍스트 참조 버그를 없앴다.

추가한 것: 만기 손익과 시나리오 표 — 원래 목표였던 "만기시 바스켓 한 단위당 손익".

VBA 는 쓰지 않았다(사용자 선택). 대신 `엔진` 시트가 이표 스케줄과 뉴턴 역산을
수행한다. 캐리가 49일치(약 2.9bp)뿐이라 **뉴턴 1회로 충분**함을 확인했다
(선도수익률 오차 0.0035bp). 단 **선도 BPV 는 y0 가 아니라 y1 에서 다시 계산**해야
한다 — y0 기준이면 0.25% 어긋나 ±100bp 에서 계약당 2만원 잔차가 생긴다.
