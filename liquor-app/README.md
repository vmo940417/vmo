# 오늘술상 (구 술이 먼저야 · 먹는거 먼저)

음식에서 술을 찾는 **페어링**과, 술 이름으로 정보를 찾는 **술 검색**을 합친 모바일 웹앱(PWA).

## 페어링 (음식 → 술)
- 첫 탭. 음식을 입력하면 와인·사케·위스키·꼬냑·중국술·전통주 스타일 54종을 점수 순으로 보여주고 (음식 323종 수록, 한 글자 오타 허용, 중식×중국술 등 같은 지역 조합 가점), 점수의 이유(산도↔지방, 탄닌↔해산물, 단맛↔매운맛 등)를 함께 표시
- 스타일을 누르면 설명·맛 프로파일·궁합과 함께 **이 스타일에 해당하는 수록 제품** 목록 (수록 3,639종 중 3,450종 연결, 맥주·기타 제외)
- 제품 상세의 '페어링' 탭 맨 위에 **어울리는 음식 TOP 6** (같은 점수 엔진)
- 점수 엔진(`pairing-engine.js`)과 데이터(`pairing-data.js`)는 [wine-sake-pairing](https://github.com/vmo940417/wine-sake-pairing) 저장소에서 Python 엔진과 결과를 대조한 뒤 복사한 생성 파일. 규칙·데이터는 그쪽에서 고친다
- 제품 → 스타일 연결 규칙은 `pairing.js` 의 `styleOf()` (품종·등급·향형·키워드 기준)

## 친구에게 공유 (설치 페이지)
- 설치 페이지: https://vmo940417.github.io/vmo/liquor-app/install.html — 카톡으로 이 링크나 `invite-card.png`(QR)를 보내면 됨
- 카톡 안에서 열면 안드로이드는 크롬, 아이폰은 사파리로 자동으로 넘김 (카톡 내장 브라우저는 설치를 못 함)
- 안드로이드: 크롬의 설치 버튼 한 번 (WebAPK, 경고 없음) · 아이폰: 공유 → 홈 화면에 추가, 또는 `sulsang.mobileconfig`(홈 화면 아이콘 프로필, 서명 없음)
- APK·IPA 파일은 만들지 않음: 카톡이 APK 전송을 막는 경우가 많고, 아이폰은 유료 개발자 계정 없이 앱 파일 설치가 안 됨

## 술 검색 (구 술이 먼저야)

와인 · 사케 · 위스키 · 꼬냑 · 중국술을 **검색(한/영/일/중)**으로 찾아
설명 · 최신 해외 시세 · 품종/원료 · 공신력 있는 평가 · 페어링 유의사항을 탭으로 보여주는 모바일 웹앱(PWA).

## 화면 구성
- 하단 탭: **페어링 / 술검색 / 분류 / 랭킹** (설정은 오른쪽 위 톱니)
- 상세 탭: **개요 / 가격 / 품종(원료) / 평가 / 페어링**

## 평가 기준
| 분류 | 기관 |
|---|---|
| 와인 | Vivino, Robert Parker(Wine Advocate), Wine Spectator, James Suckling |
| 사케 | さけのわ(Sakenowa) 평점·랭킹 |
| 위스키 | World Whiskies Awards, ISC, IWSC, San Francisco WSC |
| 꼬냑 | IWSC, ISC, San Francisco WSC, BNIC 숙성 등급 |
| 중국술 | 中国名酒(전국평주회), San Francisco WSC, Concours Mondial de Bruxelles, IWSC |

## 검색
- 라벨 사진 검색(카메라·구글 렌즈·글자 인식)은 인식 오류가 많아 2026-11 에 뺐습니다. 이름 검색만 지원합니다.
- 한국어 초성(ㅂㅂㄴ → 발베니), 일부 글자(발베), 조합 중 글자(발ㅂ, 발벤), 영어·일본어·중국어
- 입력하는 동안 수록 술 목록 + 구글 자동완성 추천어(JSONP, 실패 시 숨김) + 항상 '구글에서 검색' 항목
- 추천어를 누르면(또는 Enter) 같은 탭 형식의 결과 페이지: 위키백과·위키데이터에서 설명·생산자·국가·도수·원료를 가져오고, 분류(소주·맥주 포함)를 추정해 페어링·평가기관·시세 링크를 채움

외부 AI 연동은 없습니다.

### 수록되지 않은 술
1. 이름 키워드로 종류·품종 추론(샤또·도멘·피노누아 → 와인 등)
2. 한글명을 영문 표기로도 바꿔 위키백과(한/영)·위키데이터 동시 검색
3. 그래도 비면 Google Custom Search(설정에서 키 입력, 선택) 요약에서 도수·국가·생산자를 정규식으로 추출하고 출처 표시
4. '정보 수정'으로 직접 고치면 이 기기에서 다음 검색부터 그 값 사용
 최신 시세·평가는 각 탭의 출처 링크(Wine-Searcher, Vivino, 공식 품평회 사이트 등)로 확인합니다.

## 실행
정적 파일이라 아무 웹서버로나 띄우면 됩니다.
```bash
cd liquor-app && python3 -m http.server 8000
```
휴대폰에서 열고 "홈 화면에 추가"하면 앱처럼 설치됩니다. (서비스워커는 HTTPS 또는 localhost 필요 → GitHub Pages/Netlify/Vercel 등에 올려 사용)

## 데이터
- `data.js`·`data-extra.js` — 상세 145종(테이스팅·평가 포함)
- `data-bulk-1~7.js` — 한국 시판 위주 대량 DB. 총 3,639종(와인 2,014 · 사케 1,000 · 위스키 274 · 맥주 99 · 소주 47 · 막걸리·전통주 34 · 꼬냑 45 · 중국술 36 · 기타 90). 도수는 대표값, 참고가(₩)는 근사치
- `icons.js` — 주종별 병 일러스트(SVG)
- `data-price.js` — 참고가를 생산국 현지 소매가(현지 통화, 추정)로 통일. 앱에서 실시간 환율(open.er-api.com)로 USD 환산
- `data-scores.js` — 유명 와인 점수 범위 + 한국 인기 와인 브랜드·라인별 Vivino 평균 근사치
- 사케 중 `lineup: true` 항목은 실재 브랜드·양조장의 등급별 '대표 라인업' 기준(실제 상품명·사양은 다를 수 있음, 앱에 표시). 가격은 수집 시점 참고 범위, 평가는 최근 빈티지/출품 기준 통상 범위 또는 확인된 수상 이력.
